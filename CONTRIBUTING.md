# Contributing

Thank you for taking an interest in Snippets. It really is appreciated.

The way this project is set up, the code is written and kept in one place by the Trindle project, so code changes from outside are not taken. That has nothing to do with the quality of anyone's work. It simply works best when we hear what went wrong and fix it ourselves.

So the most useful thing you can send is a description:

- **Something broken?** Tell us what you did, what you expected, and what happened instead. The version you are running and the program you were typing into help a great deal. A screenshot is welcome too.
- **An idea?** Tell us what you were trying to do and where Snippets got in the way. You do not need to suggest how to fix it.
- **A security problem?** Please report it privately rather than in a public issue. [SECURITY.md](SECURITY.md) explains how.

Report bugs on [Buildmorphic](https://buildmorphic.com).

Snippets is GPL v3, so you are always free to fork it and take it in your own direction.
